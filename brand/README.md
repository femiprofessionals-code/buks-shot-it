# Buks Shot It: brand assets (v1.0)

Deliverable 2, Visual Identity and Logo. Status: awaiting client approval.

## Folders

| Folder | Contents |
| --- | --- |
| `logo/svg/` | Production logo files. Vector, letters converted to outlines, no fonts needed. |
| `logo/png/` | Transparent PNG exports (2000 px wordmarks, 1200 px monograms, 1080 px avatars, favicons 16/32/180/512 px). |
| `tokens/` | Design tokens (`tokens.css`, `tokens.json`) for the website build. |
| `mockups/` | Rendered presentation mockups. **Not logo files**: never use them for production. |
| `guidelines.html` | The brand guidelines page (published as an Artifact). |

## Logo files

| File | Use |
| --- | --- |
| `buks-wordmark-primary.svg` | Charcoal + bronze point, on ivory or white |
| `buks-wordmark-reverse.svg` | Ivory + bronze point, on charcoal |
| `buks-wordmark-black.svg` / `-white.svg` | One colour: single-ink print, embossing, watermarks |
| `buks-lockup-tagline-*.svg` | Wordmark with "EVERY FRAME, CONSIDERED." |
| `buks-monogram-*.svg` | BSI monogram: avatars, foil, square watermarks |
| `buks-social-avatar-dark.svg` / `-light.svg` | 1080 × 1080 profile images |
| `favicon.svg` | "B." browser icon |

## Core specification

- Colours: Charcoal #171717, Warm Ivory #F5F1EA, White #FFFFFF, Muted Bronze #A88962 (graphics only on light backgrounds), Deep Bronze #7D6240 (text accent on light).
- Typefaces: Ibarra Real Nova (display, logo) and Schibsted Grotesk (text, UI), both SIL Open Font License.
- Clear space: the height of the capital B on every side.
- Minimum sizes: wordmark 120 px / 30 mm; monogram 24 px / 8 mm (one colour).
